# Robot Collector Arena

This project is a playable 3D Godot prototype for a robot-collecting and fighting game.

Features included in the starter prototype:
- 3D player movement and camera controls
- Default robot model before selection
- Robot selection screen with color customization
- Weapon switching between gun and melee
- Basic enemy AI
- Scrap pickup and shop-style unlocking
- Persistent robot and weapon progress using local save data

How to run:
1. Open this folder in Godot 4.x.
2. Press F5 or click Run.
3. Use WASD to move, Mouse to look, Left click to fire, Right click to melee, 1/2 to switch weapons.

Controls:
- WASD: Move
- Mouse: Look around
- Left Click: Fire gun
- Right Click: Melee attack
- 1: Pulse Gun
- 2: Shock Saber
- Esc: Release mouse cursor

Notes:
- This is a prototype using placeholder geometric robot models.
- You can replace the blocky robot meshes with your own models later.
- Robot upgrades and weapon unlocks persist between runs using local save data.
